The MegaHome Care app has these core features:

1. **Admin Scheduling** — Admin creates and manages scheduling for clients and caregivers
2. **Account Management** — Admin creates accounts for both clients and caregivers
3. **Geo-fenced Clock-in** — Caregivers can only clock in within 100m of the client's address
4. **Shift Reports** — Only caregivers can create reports for their shifts
5. **PDF Scheduling** — Admin can generate a PDF of the client's schedule and send it to the client
6. **Family Members** — Admin can add up to 3 family members per client account

**Why:** These are the primary selling points of the app and should be reflected on the landing page features section.

**How to apply:** Use these features when updating the landing page content, especially the features section, to accurately represent what the app does.
